# Лабораторна робота 0 — Синтаксис Java

**4 бали**

## Мета

Підняти робоче середовище Java на власному комп'ютері та побачити,
як знайомі з C++ конструкції виглядають мовою Java.

Ця робота навмисно не про алгоритми. Усі задачі всередині ви вже
розв'язували на C++. Складність в іншому: встановити JDK, зібрати
проєкт, запустити тести й здати результат через Git.

## Завдання

У файлі `src/main/java/ua/university/BasicOperators.java` реалізувати
статичні методи так, щоб проходили всі тести. Зараз методи повертають
`null`, `0` або `false` — це заготовки.

Контракт кожного методу описаний у javadoc над ним: що метод повертає,
як поводиться на межових значеннях, коли кидає виняток. Читайте javadoc,
а не вгадуйте за назвою.

Теми, які покривають методи:

- арифметика та цілочисельне ділення
- розгалуження: `if`, `switch`
- цикли
- одновимірні та двовимірні масиви
- рядки
- викидання винятків (`IllegalArgumentException` на некоректний вхід)

Критерій готовності один: **`./gradlew test` проходить повністю**.

## Обмеження

**Не змінюйте `src/test/java/ua/university/BasicOperatorsTest.java`.**
Це тести, за якими перевіряється робота. Автоперевірка все одно
підставляє еталонну версію, тож правки в цьому файлі нічого не дадуть.
Якщо вам здається, що тест помилковий — напишіть викладачу, можливо
ви маєте рацію.

**Не змінюйте сигнатури методів** у `BasicOperators`: назви, параметри
й типи повернення мають лишитися такими, як є. Всередині методів
пишіть як вважаєте за потрібне.

Стандартна бібліотека дозволена, але подумайте двічі: `Arrays.sort`
у `sortArray` формально пройде тест, проте сенс завдання — написати
цикл самостійно.

## Як перевірити себе

```
./gradlew test
```

У Windows — `gradlew.bat test`.

Запускайте після кожного написаного методу, а не в кінці. Перший
запуск довгий: Gradle качає себе й залежності.

Побачити, який тест впав і чому:

```
./gradlew test --info
```

Детальний HTML-звіт: `build/reports/tests/test/index.html`

## Якщо щось не працює

| Симптом | Причина |
|---|---|
| `./gradlew: Permission denied` | виконати `chmod +x gradlew` |
| `JAVA_HOME is not set` | JDK не встановлено або не в PATH |
| Кракозябри у виводі (Windows) | виконати `chcp 65001` |
| Не збирається одразу після встановлення JDK | перезапустити термінал |

Не витрачайте на налаштування більше пів години наодинці — пишіть.
